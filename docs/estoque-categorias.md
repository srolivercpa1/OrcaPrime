# Categorias automáticas do estoque

A categoria é identificada pelo início da descrição: Bateria iPhone vai para Bateria; Tela Samsung para Tela; Cabo USB para Cabo. Tipos diferentes geram categorias próprias pela primeira palavra. Tipos comuns no plural, como Baterias e Telas, são reunidos no singular. Descrições que começam apenas com números ficam em Outros: informe o tipo do produto no início para classificar.

A regra se aplica também às peças já cadastradas. Use Categoria para ver um grupo ou Todas as categorias para consultar o estoque completo, ordenado por categoria e descrição. A busca por nome ou código funciona junto com o filtro.

Ao alterar o início da descrição e salvar, a categoria é atualizada automaticamente. Quantidades, valores, códigos e histórico de movimentações permanecem intactos. A versão do aplicativo continua 1.0.
